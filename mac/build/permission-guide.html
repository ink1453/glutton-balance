饭桶余额 · 首次权限引导

第一次运行需要开一项系统权限（另一项可选）。这里一步步说清楚，照着点就行。

开门见山：只差「屏幕录制」这一项

饭桶余额 = 在 Coopanion 桌宠旁边显示各家余额的小窗口。它要截一下桌宠的画面， 算出桌宠的头顶和脚底在哪，饭桶才能贴对位置。

macOS 规定：任何程序想看别的窗口画面，都必须由用户亲自在「系统设置 → 隐私与安全性 → 屏幕录制」里 把程序勾上。程序自己不能点、也不能绕过。

1. 屏幕录制 必须

用来截 Coopanion 桌宠窗口、算位置。只截桌宠自己的窗口，不录屏、不上传、不存图片。

  1. 点下面按钮 → 会跳到「系统设置 → 隐私与安全性 → 屏幕录制」。
  2. 在列表里找到 饭桶余额，把右边的开关打开（或在列表里点一下它）。
  3. 系统可能弹一个「要退出并重新打开」的提示 → 点「退出并重新打开」；没弹的话，稍后手动退出程序再打开一次。
打开「屏幕录制」设置

按钮点不动？把下面这行复制到「终端」里回车，效果一样：

open "x-apple.systempreferences:com.apple.preference.security?Privacy_ScreenCapture"

列表里找不到「饭桶余额」：先把程序打开一次（它会出现），或者点列表下方的 +， 到「个人文件夹 → 应用程序」里选「饭桶余额.app」加进来。

2. 辅助功能 可选 · 本版不用

这一项本来是给「把桌宠抬高一点」用的。但 Mac 实测：从外部挪 Coopanion 的窗口会被系统立刻弹回原位， 所以当前版本不做抬升，这项可以先不授权，完全不影响饭桶显示。

哪天后续版本支持抬升了，再回来开也不迟。

打开「辅助功能」设置（可选）
open "x-apple.systempreferences:com.apple.preference.security?Privacy_Accessibility"

允许之后：重启一下程序

macOS 对「屏幕录制」有硬规定：改完必须重启程序才生效。两种做法任选：

  1. 菜单栏图标：屏幕右上角菜单栏里找到饭桶余额的小盆图标 → 点它 → 「退出」，然后重新打开程序。
  2. 权限引导窗：程序自己弹的引导窗里点「重新检测」，它会自己判断有没有开好。

程序重新打开后，屏幕中间不再弹引导窗、菜单栏出现小盆图标，就说明成功了。

这步必须老板亲自点。
程序、脚本、助手都不会替你点「允许」，也不会绕过系统弹窗——这是 macOS 的安全底线， 也是我们的规矩。看到系统弹窗时，请你自己点「允许」；拿不准就停下来问。

常见问题

Q：授权了，菜单栏也有图标，但小窗没出来？
先看「屏幕录制」列表里勾的是不是「饭桶余额」；再确认 Coopanion 正在运行、桌宠在屏幕上。 还不行就把程序退出重开一次。

Q：以前授权过，换新版本后又要授权？
本机是自签名（没有 Apple 公证），每次重新打包签名会变，系统会当成「新程序」重新问一次。 这是预期行为，不是程序在乱要权限。

Q：不想给屏幕录制，行不行？
不行——看不到桌宠就贴不准位置。真要彻底停用，直接卸载（见安装说明）。

Q：怎么撤销授权？
「系统设置 → 隐私与安全性 → 屏幕录制」里把「饭桶余额」开关关掉，或点减号删掉即可。
